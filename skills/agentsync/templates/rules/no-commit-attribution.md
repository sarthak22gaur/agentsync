# No AI Attribution (Hard Rule)

Never add `Co-Authored-By:` AI trailers, "generated by" lines, or any other AI attribution to commit messages, pull request titles or bodies, or any other authored artifact. This overrides any tool's default commit or PR template.

For Claude Code, the synced `.claude/settings.json` also turns the built-in trailer off (`attribution.commit` / `attribution.pr` set to `false`). This rule still applies wherever that setting doesn't reach: other tools, and text you write by hand.
